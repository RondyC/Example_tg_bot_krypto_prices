Техническое Задание (ТЗ): Многопользовательский Телеграм-Бот для выбора криптовалют

Цель проекта - создание многопользовательского Телеграм-бота, который предоставляет информацию о криптовалютах и позволяет выбирать в различных ценовых диапазонах. Бот поддерживает многопользовательский режим, обеспечивая уникальное взаимодействие с каждым пользователем.


Установить зависимости:
pip install -r requirements.txt

Создать файл .env на основе .env.template и заполнить его токеном и ключом API.

Запустить бота:
python main.py

Команды бота
/start - Приветственное сообщение и список доступных команд.
/high - Показать список дорогих криптовалют. (Endpoint: /high)
/low - Показать список дешевых криптовалют. (Endpoint: /low)
/custom - Ввести диапазон цен и получить список криптовалют в этом диапазоне. (Endpoint: /custom)
/history - Показать последние 10 запросов пользователя.

Этот проект использует Python, Telegram Bot API, и RapidAPI для получения данных.

Состояния пользователей и запросы хранятся в базе данных SQLite для обеспечения многопользовательской поддержки.

Использование бота
Запустите бота, отправив ему команду /start.
Используйте команды /high, /low, /custom для получения списка в различных ценовых категориях.
При использовании команды /custom, следуйте инструкциям по вводу минимальной и максимальной цен.
Команда /history покажет вам последние запросы пользователя.

Каждый эндпоинт возвращает JSON-данные, которые бот форматирует в табличный вид для удобного представления пользователю.
